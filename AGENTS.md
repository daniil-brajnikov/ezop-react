# Инструкции для агентов

## О проекте

Это legacy-фронтенд интерфейса ЭЗОП, встроенный в Drupal.
Стек: TypeScript 3.7, React 16, Redux, Webpack 4, SCSS-модули.
Бэкенд и Drupal находятся вне этого репозитория.

## Среда и команды

- Используйте Node.js 12 и Yarn 1.22.22.
- Для установки зависимостей используйте `yarn install`; не заменяйте Yarn на npm и не меняйте `yarn.lock` без необходимости.
- Доступные проверки:
  - `yarn lint`
  - `yarn check-types`
  - `yarn build`
- Автотестов в проекте нет. Если меняете поведение, выполните доступные статические проверки.

## Важные ограничения интеграции

- Приложение получает начальные данные из `window.serverData`; типы находятся в `src/global.d.ts`.
- HTTP-запросы к серверу ЭЗОП реализованы в `src/redux/helpers/request.ts`.
- Серверные ответы могут быть в кодировке Windows-1251. Не заменяйте текущую обработку кодировки и HTML-ответов без отдельной необходимости.
- `webpack.common.js` выводит сборку во внешний каталог `../xampp/htdocs/ezop/ezop-react`.
  Не меняйте путь сборки, `publicPath` или серверные URL без явной задачи на изменение интеграции.
- `yarn start` также пишет файлы в этот внешний каталог. Локальный запуск интерфейса без Drupal/ЭЗОП не покрывает полноценную функциональность.

## Архитектура и стиль изменений

- `src/components/` — презентационные React-компоненты.
- `src/containers/` — подключение компонентов к Redux.
- `src/redux/modules/` — reducers, actions и thunk-операции по предметным областям.
- Новую серверную логику размещайте рядом с существующей интеграцией, не дублируйте запросы в компонентах.
- Сохраняйте TypeScript-типизацию и существующий стиль проекта: функциональные компоненты, Redux actions через `typesafe-actions`, SCSS-модули.
- Не выполняйте массовую модернизацию зависимостей, Webpack, React или TypeScript вместе с функциональной задачей.
- Не изменяйте пользовательские или уже существующие незакоммиченные изменения, если это не требуется задачей.

## Перед завершением

Для затронутого кода выполните `yarn lint` и `yarn check-types`; при изменении сборки или ассетов также выполните `yarn build`.
В итоговом сообщении укажите выполненные проверки и известные ограничения, связанные с недоступным внешним бэкендом.
