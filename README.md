# ЭЗОП React

Фронтенд интерфейса создания, редактирования и использования черновиков онтологий и онтологий на веб-сервере ЭЗОП.

Проект является частью более крупной системы на Drupal. Этот репозиторий содержит только React-приложение: Drupal, сервер ЭЗОП и исполняемый модуль `editor.exe` находятся вне него.

## Стек

- Node.js 12
- Yarn 1.22.22
- TypeScript 3.7
- React 16
- Redux и redux-thunk
- Webpack 4
- SCSS-модули

## Требования

Для установки зависимостей и сборки необходимы:

- Node.js 12;
- Yarn 1.22.22;
- доступ к каталогу, в который развернут основной проект ЭЗОП/Drupal, если требуется проверить интеграцию с сервером.

Проект использует старые версии зависимостей, в частности `node-sass`, поэтому на более новых версиях Node.js установка или сборка может завершиться ошибкой.

## Установка

```bash
yarn install
```

Для воспроизводимой установки используйте Yarn и файл `yarn.lock`. Не заменяйте их npm без отдельной задачи по миграции.

## Команды

```bash
# Запуск webpack-dev-server
yarn start

# Production-сборка
yarn build

# Проверка TypeScript
yarn check-types

# Проверка ESLint
yarn lint
```

Автоматические тесты в репозитории пока отсутствуют.

## Сборка и локальная разработка

Конфигурация Webpack намеренно выводит файлы не в `dist`, а во внешний каталог:

```text
../xampp/htdocs/ezop/ezop-react
```

Этот путь задан в `webpack.common.js`. Команда `yarn start` также пишет собранные файлы в него.

Такое устройство нужно для встраивания приложения в локальное развёртывание ЭЗОП/Drupal. Не изменяйте путь сборки или `publicPath` без задачи, которая явно затрагивает интеграцию.

## Интеграция с сервером ЭЗОП

Начальные данные интерфейс получает от страницы Drupal через глобальный объект `window.serverData`. Его типы описаны в `src/global.d.ts`.

Клиент взаимодействует с сервером ЭЗОП по относительным URL, в том числе:

- `/ezop/exe/editor.exe`;
- `../proc_data.php`.

Запросы и обработка ответов находятся в `src/redux/helpers/request.ts`. Серверные ответы могут приходить в кодировке Windows-1251 и содержать HTML; текущая обработка этих особенностей необходима для корректной работы.

Запуск одного только React-приложения без Drupal и сервера ЭЗОП позволяет проверить только интерфейс, но не сохранение, построение онтологий, выполнение запросов и словарь.

## Структура проекта

```text
src/
  components/       презентационные React-компоненты
  containers/       подключение компонентов к Redux
  redux/
    modules/        reducers, actions и thunk-операции
    helpers/        общие функции и HTTP-интеграция
  icons/            SVG-иконки
  style/            глобальные стили и переменные цветов
  global.d.ts       типы данных, передаваемых сервером
```

## История

Исходная версия проекта создана в 2020 году. В код были внесены изменения в 2022 и 2025 годах. В отдельных местах реализация может отличаться от описаний в связанных текстах дипломов: при доступе к исходному коду некоторые решения были скорректированы.
